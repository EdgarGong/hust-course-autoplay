# 华科智课连播 · HUST Course Autoplay

面向华中科技大学《研究生心理健康》课程的浏览器扩展，提供自动连播和自动 2 倍速播放，减少视频之间反复手动切换、点击播放的操作。

当前版本：**1.2.3**。使用 Manifest V3，原生 JavaScript/CSS，无构建步骤、无第三方运行依赖。

## 适用课程

为华中科技大学《研究生心理健康》课程提供自动连播和 2 倍速播放辅助。

## 功能

- **自动连播**：视频自然结束后检查页面任务状态，按顺序播放本节下一个视频或打开下一节。
- **自动 2 倍速**：开启连播后，对当前视频及新加载的视频设置 2 倍速，在媒体加载和开始播放时重新应用。
- **播放确认和重试**：等待播放器加载，确认视频已进入播放状态后才结束启动重试。
- **保留声音设置**：不主动修改播放器的静音状态或音量。
- **测验留待手动作答**：仅剩章节测验时可继续下一节，之后需自行返回补做；其他未完成任务可能使续播停止。
- **按课程、按标签页保存开关**：使用当前标签页的 `sessionStorage`，不同课程分别保存。

## 安装

先在本仓库点击 **Code → Download ZIP** 并解压，或执行 `git clone https://github.com/EdgarGong/hust-course-autoplay.git`。Chrome 和 Edge 使用同一份项目文件。

### Chrome

1. 地址栏输入 `chrome://extensions/`。
2. 打开右上角的**开发者模式**，点击**加载已解压的扩展程序**。
3. 选择包含 `manifest.json` 的项目根目录，而不是 ZIP 文件或它的上一级目录。
4. 刷新已经打开的课程学习页面，即可看到左下角的**开启连播**按钮。

### Microsoft Edge

1. 地址栏输入 `edge://extensions/`。
2. 开启**开发人员模式**，点击**加载解压缩的扩展**。
3. 选择包含 `manifest.json` 的项目根目录，而不是 ZIP 文件或它的上一级目录。
4. 刷新已经打开的课程学习页面，即可尝试使用左下角的**开启连播**按钮。

本项目通过开发者模式手动安装。Edge 支持加载此类扩展，但尚未单独实测完整课程流程；如遇问题，欢迎提交 Issue。

## 使用

1. 正常登录华科课程平台并进入《研究生心理健康》的章节学习页。
2. 点击页面左下角的**开启连播**，扩展会尝试播放当前视频并设置 2 倍速。
3. 视频自然结束后，扩展等待平台更新任务状态，再尝试继续播放。
4. 点击同一个按钮可关闭连播。关闭后停止自动设置倍速，当前速度保持不变，可在播放器中手动调整。
5. 返回课程目录，检查并完成所有测验及剩余任务。

更新扩展文件后，在扩展管理页点击本扩展的**重新加载**，再刷新课程页。

## 常见问题

### 下一节打开了，但没有自动播放？

先看左下角提示。加载失败或仍有未完成任务时，扩展可能停止续播；如果显示“浏览器限制有声自动播放”，请在播放器内点一次播放。脚本点击不能保证满足浏览器的真实用户操作要求，扩展不会通过静音来强行启动。

### 切到后台后视频暂停？

扩展不会设置“失焦暂停”。可先取消**播放器内**的静音，并将音量调至大于零；若需要无声播放，可以尝试右键 Chrome 标签页选择**将网站静音**。这两种静音方式不同。浏览器节能策略、后台计时器限制及平台行为仍可能影响后台播放，本项目不保证无人值守或后台持续连播。

### 为什么视频仍然是静音？

1.2.1 及更早版本会设置默认静音；更新后请在播放器中手动取消一次。1.2.2 起不再主动修改音量和静音状态。

### 为什么看完视频后课程还没通过？

扩展不会代答测验，请回到目录检查并完成剩余任务。学习进度和成绩以平台显示为准。

## 运行范围与数据

内容脚本仅在华科课程平台的章节学习页运行，并进一步检查学习页路径及 `courseId` 参数。

- 不要求额外的 `tabs`、`cookies`、`webRequest` 等扩展 API 权限。
- 脚本读取学习页及可访问的嵌套播放器 DOM，调用正常播放和倍速接口。
- 本扩展自身没有数据上传接口、分析服务或外部运行依赖。
- 连播开关及临时导航状态保存在页面源所属的 `sessionStorage`，不写入 GitHub。

## 本地开发与验证

使用 Node.js 22 或更高版本，无需 `npm install`：

```sh
node --check autoplay.js
node --test tests/autoplay.test.cjs
```

目前有 17 项回归测试，覆盖倍速设置、关闭开关、音量保留、播放启动确认、临时失败重试和自动播放被拒绝等行为。测试通过 Node VM 模拟浏览器及 iframe 边界，**不等于真实课程页面的端到端验证**。

手动验证时可检查：首次开启播放、下一视频/下一章节续播、静音和后台行为、测验任务提醒、关闭连播后的手动控制。平台页面结构更新可能导致选择器失效。

提交 Issue 时请说明浏览器名称和版本、扩展版本、操作步骤和左下角提示；避免上传带账号、学号、登录参数的完整学习页 URL 或截图。
